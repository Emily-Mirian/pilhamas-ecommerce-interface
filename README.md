# Pilhamas - E-commerce de Pijamas

Projeto de interface para loja virtual desenvolvido para a disciplina de Desenvolvimento Web do curso de **Engenharia de Software**.

## Tecnologias Utilizadas
* **HTML5**: Estruturação semântica das páginas.
* **CSS3**: Layouts com Flexbox e Grid, design responsivo e gradientes.
* **JavaScript**: Lógica de interatividade (em desenvolvimento).

## 📋 Funcionalidades
* Catálogo de produtos dividido por categorias (Bichinhos, Comidas, Desenhos).
* Página de cadastro de usuários com validação visual.
* Design focado em UX (User Experience) e navegabilidade.
